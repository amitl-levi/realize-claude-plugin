- **Install behavior — dual-platform manifests + SessionStart MCP auto-install hook** ported from `realize-buyer-agent` (Jun 2026):
  - **`.codex-plugin/plugin.json`** (new) — Codex parity manifest. References the same `../.mcp.json`, the same `../os/guardrails.md` system prompt, and the same `../knowledge/` topic layer used by the Claude Code build. Rebranded from `realize-buyer-agent` to `realize-ads-api`; Omnicom-flavored description stripped. Sections that don't apply to the public plugin (workflows/, clients/, docs/install) were not ported.
  - **`.claude/settings.json`** (new) — declares a SessionStart hook (matchers: `startup|resume|clear`) that runs `scripts/ensure-realize-mcp.sh` on every fresh / resumed / cleared session.
  - **`scripts/ensure-realize-mcp.sh`** (new) — idempotent installer for the hosted Realize MCP server. On first session: runs `claude mcp add --transport http --callback-port 3000 realize-mcp https://mcp.realize.com/mcp` and tells the user to `/mcp` to authenticate. On subsequent sessions where the server is already wired correctly: silent no-op (B19 polish). On detected URL / callback-port customisation: one-line warning, never auto-repair (respects user intent). Verbose diagnostics behind `ENSURE_REALIZE_MCP_VERBOSE=1`. Plugin-name banner rebranded; `CLAUDE.md B18` / sandbox cross-refs stripped.
- **Knowledge layer expansion** ported from the upstream `realize-buyer-agent` (Jun 2026):

  - Section-merged additions into 6 existing topic files: `bidding.md` (Bid Levers matrix + Learning-Period Guard + KPI→objective mapping), `creative.md` (3P JS-tag validator allowlist + recipe + Wilson-score creative ranking with statistical validity tiers), `targeting.md` (6-dimension narrow-targeting diagnostic + Tier-1 market check + small-market caveat + pixel vs CRM retargeting), `campaign-structure.md` (platform/device-split rules + Realize+ Phase 1/2 framing + cross-period % share comparison), `budget.md` (Depletion-Miss Investigation + cross-period % share comparison + 7-day short-burst split), `site-management.md` (Historical Top-N publisher block guard + approved-list dynamics + block-attribution families).
  - `agents/realize-analyst.md` Tool Reference now documents `get_campaign_reach_estimate`; available-slugs list updated to include the two new topics.
- New `optimize-campaign` skill — data-driven diagnosis and recommendation loop grounded in Taboola's [official performance optimization guide](https://www.taboola.com/help/en/articles/3878108-how-to-improve-campaign-performance). Covers the 100+ clicks per item threshold, 8× CPA goal daily-spend rule, metric-combination prescription rules (CTR × CVR × CPA), and concrete UI-action recommendations with exact UI paths.
- Embedded the **realize-toolkit** as a knowledge layer. Plugin now ships `os/guardrails.md` (consolidated system-prompt: brand, tone, output structure, attribution, formatting, entity references), `knowledge/` (10 topic MDs: bidding, budget, brand-safety, campaign-structure, creative, custom-rules, environments, site-management, targeting, tracking, plus manifest.json), and `scripts/brand-check.sh` (linter, adapted to allow `item_id` as a public MCP parameter). Agent (`realize-analyst`) loads `os/guardrails.md` at session start and consults `knowledge/<slug>.md` for topic-specific Realize questions.
